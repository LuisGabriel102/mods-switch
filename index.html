Motor de Mods do Switch

Mods de jogabilidade para jogos de Switch: deixar mais forte, mexer nas porcentagens, dar itens… mas sempre com uma troca, para o jogo ficar diferente, não mais chato.

⚖️A regra de ouro

➕ VOCÊ GANHA
um poder novo
⇄
➖ VOCÊ PAGA
com outra coisa

A ideia não é tirar a diversão: é criar um jeito novo de se divertir. Por isso todo mod tem as duas caixas — a verde e a vermelha.

🧭Como ativar um mod (4 passos)

📝

1. A receita

Cada mod é uma receita: um arquivo de texto com uma regra por linha. A regra diz qual número do jogo mudar e como.

*trinkets/*|entries#*|limit    x2

Lê-se: “em toda bugiganga, o limite de iguais vezes 2”.
x1.5 multiplica · +10 soma · -10 tira · =45 valor fixo · min/max limites · so/menos escolhem onde vale.

⬇️
⚙️

2. O motor monta e confere (no PC)

python -I motor.py dd1 mod colecionador

O motor lê o jogo, aplica as regras, grava só os arquivos mudados e relê tudo para conferir. Se uma regra não achar nada, ele para e não grava nada (nada sai pela metade).

🧩 Vários mods juntos: mod colecionador+pacto_escuridao

⬇️
💾

3. Levar para o Switch (escolha um caminho)

⭐ RECOMENDADO

🗂️ Cartão SD (pasta do Atmosphere)

python -I motor.py dd1 sd colecionador

Copie a pasta atmosphere que ele cria para a raiz do cartão. O jogo instalado continua original; o mod entra “por cima”.

🔴 Desligar: apague atmosphere/contents/<código do jogo>.

⚠️ Um mod por jogo de cada vez — para vários, junte com a+b.

📦 NSP instalado

python -I motor.py dd1 trancar colecionador

Gera o NSP do jogo (e um por DLC mudada) para instalar pelo DBI, como as traduções.

🔴 Desligar: reinstalar o jogo original.

⬇️
🎮

4. Jogar

💾 Antes, faça backup do save (JKSV).

⏱️ Mod de regra (crítico, chance, preço) vale na hora. Mod de começo de partida (ouro inicial, heróis iniciais) só vale numa partida nova.

🚦O que cada selo quer dizer

✅
Pronto
A receita existe e foi conferida no PC. Falta só testar no Switch.
🔧
Valor achado
Já sei onde fica o número no jogo. Falta escrever a receita.
💡
Ideia
Falta abrir e estudar o jogo. Pode ser que o valor esteja no código (aí não dá).
